## Reporting a Vulnerability

The maintainers take security vulnerabilities seriously and appreciate responsible disclosure.

If you discover a security issue in this project, **please do not open a public issue**.

Instead, report it privately using one of the methods below.

### Preferred Method

Open a **GitHub Private Vulnerability Report** via the repository's Security tab.

### Alternative Method

Email the maintainer directly with the subject:

```
[SECURITY] Vulnerability Report – Whimsical Times
```

Please include the following information:

* Description of the vulnerability
* Steps to reproduce (PoC if available)
* Potential impact and attack scenarios
* Suggested mitigation (if known)

---

## Disclosure Policy

After a report is received, the maintainers will:

1. Acknowledge the report within **3–5 days**
2. Investigate and validate the vulnerability
3. Work on a fix and prepare a patch
4. Coordinate disclosure with the reporter

Responsible disclosure is expected. Please allow time for a fix before public disclosure.

---

## Scope

This policy applies to:

* The web application
* Deployment configuration
* Client-side security
* Third-party integrations

---

## Safe Harbor

Security researchers acting in good faith and following this policy will **not be subject to legal action**.

We appreciate the work of security researchers who help keep this project safe ❤️
